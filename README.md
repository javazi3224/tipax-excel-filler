# فرم مرسولات تیپاکس (اپ مستقل اکسل‌ساز)

این یه اپ اندروید کاملاً مستقله (هیچ ربطی به سایت یا اینترنت نداره) که برای هر گیرنده فقط ۴ تا فیلد ازت می‌گیره:

- نام و نام خانوادگی گیرنده
- شهر مقصد (از لیست رسمی شهرهای تیپاکس، با جستجوی خودکار)
- آدرس کامل گیرنده
- شماره موبایل گیرنده (۱۱ رقمی)

و وقتی چند تا ردیف اضافه کردی، با زدن دکمه‌ی «ساخت فایل اکسل و اشتراک‌گذاری»، دقیقاً همون فایل اکسل رسمی تیپاکس (با همون استایل، همون لیست شهرها، همون شیت‌های کمکی) رو می‌سازه و فقط همین ۴ ستون رو پر می‌کنه - بقیه‌ی فایل دست‌نخورده می‌مونه تا تو سیستم تیپاکس بدون مشکل آپلود بشه.

فایل ساخته می‌شه و بلافاصله صفحه‌ی اشتراک‌گذاری (بله، تلگرام، واتساپ، ایمیل و ...) باز می‌شه تا بفرستیش؛ جایی رو گوشی (مثل پوشه‌ی Download) ذخیره نمی‌مونه.

**تایپ صوتی**: چون همه‌ی فیلدها کادر متنی معمولی‌ان، دکمه‌ی میکروفونِ خودِ کیبورد گوشی (مثلاً Gboard) روشون کار می‌کنه - نیازی به کد یا مجوز اضافه نبود.

## قفل دو مرحله‌ای (کسی بدون اجازه نتونه ازش استفاده کنه)

۱. **فعال‌سازی گوشی** - بار اولی که اپ رو رو یه گوشی جدید نصب و باز می‌کنن، یه «کد گوشی» منحصربه‌فرد (مثل `A1B2-C3D4`) نشون داده می‌شه. اپ اصلاً باز نمی‌شه مگر این‌که یه «کد فعال‌سازی» ۶ رقمی وارد بشه که **فقط خودت** می‌تونی بسازیش.
   - فایل `activation_tool.html` همین پوشه رو با مرورگر (آفلاین، بدون اینترنت) باز کن، کد گوشی‌ای که برات فرستادن رو وارد کن، کد فعال‌سازی رو بهش بده.
   - یعنی حتی اگه فایل APK دست هرکسی بیفته، بدون تایید تو نمی‌تونه ازش استفاده کنه.
۲. **رمز شخصی** - بعد از فعال‌سازی، هر کاربر یه رمز برای خودش تعریف می‌کنه (قابل تغییر از داخل اپ).

⚠️ نکته: اگه بعداً خواستی این ابزار فعال‌سازی رو با الگوریتم/رمز دیگه‌ای بسازی، باید رشته‌ی `ACTIVATION_SECRET` هم تو `app/src/main/java/.../LockActivity.kt` و هم تو `activation_tool.html` دقیقاً یکی بمونه، وگرنه کدها جور درنمیان.

## چطور APK بسازم؟

همون دو راهی که برای اپ قبلی (پوسته‌ی سایت) گفته شد:
1. **گیت‌هاب اکشنز** (ساده‌ترین راه، بدون نصب چیزی رو کامپیوتر): این پوشه رو تو یه ریپازیتوری گیت‌هاب آپلود کن (محتویات پوشه رو با drag & drop بکش، و فایل `.github/workflows/build-apk.yml` رو چون پوشه‌ی نقطه‌دار با drag & drop نمیاد، با «Create new file» و تایپ مستقیم مسیر بساز). بعد از Commit، خودش تو تب Actions می‌سازتش و از "Artifacts" دانلودش کن.
2. **اندروید استودیو**: پوشه رو باز کن، Gradle Sync کن، `Build > Build APK(s)`.

## نکته‌ی مهم

فایل `app/src/main/assets/template.xlsx` دقیقاً همون فایلیه که خودت فرستادی - اگه بعداً تیپاکس فرمت رسمی‌ش رو عوض کرد، این فایل باید آپدیت بشه.
